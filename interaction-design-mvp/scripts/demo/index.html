    第五步 · 在已有开发环境中使用
    平时通过宿主 Agent 或命令行调用
    
      
    方式一：交给宿主 Agent
    在已配置 ALPD skill 的宿主会话中，提供结构路径和设计要求。让 Agent 先整理任务、检查缺失项，再使用同一套命令执行与导出。
    请使用 ALPD 检查我提供的目标结构和约束。先列出需要我确认的内容，任务和运行环境检查通过后，按指定评估预算执行，并导出报告及三维浏览页面。
    插件接入和本地模型环境需要提前准备。此离线 demo 用于浏览，不会启动宿主会话。
    
      
    方式二：使用命令行
    # 1. 创建草稿，然后编辑并检查
alpd task init --name my_design --output brief.json
alpd task review brief.json

# 2. 补齐输入后编译、检查本地环境
alpd task build brief.json --output task.json
alpd pipeline preflight task.json --runtime runtime.json

# 3. 准备真实计算；返回 pipeline_dir
alpd pipeline prepare task.json --runtime runtime.json \
  --strategy harness --batch-size 1 --max-evaluations 2
alpd pipeline run <pipeline_dir>

# 4. 每轮读取请求，宿主按要求写 decision.json 并提交
alpd pipeline observe <pipeline_dir>
alpd pipeline apply <pipeline_dir> --decision decision.json

# 5. 完成后导出，在浏览器打开 results/index.html
alpd pipeline export <pipeline_dir> --output results
    真实计算需要本地模型与运行配置。复合物评估预算不限制候选生成和单体检查的工作量。
    
      
    仅查看已有结果
    alpd viewer export <existing-result-bundle> --output viewer.html
    已有记录可以单独导出三维页面，无需再次生成或评估。输出文件与目录都应使用新路径。
