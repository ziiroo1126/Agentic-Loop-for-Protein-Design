What the loop does

Supplied task → generation → monomer checks → agent selection → complex evaluation → next selection or stop → report and 3D export.

ALPD is a computational-only research project; wet-lab work is outside its scope. Validation focuses on reproducible workflows, computational benchmarks, baseline comparisons, ablations and measured costs. The current pipeline selects evaluations; automatic redesign from feedback is future work. Model scores are computational diagnostics, and these cases have not demonstrated a stable advantage over baseline selection.
