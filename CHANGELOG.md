## 0.1.0 — Research Preview — 2026-09-07

- Publish ALPD as a protein binder workflow with a shared host skill, a Python
  scientific core and portable offline reports.
- Unify plugin/skill/tool names under ALPD; add the `alpd` CLI while retaining
  `interaction-design` as an existing-script alias.
- Provide browser, synthetic CPU and real-model quick-start paths, plus a default
  Codex project installation and resource diagnostics.
- Publish a complete recorded two-candidate case, its original decisions and
  structures, and a separate cached adaptive case with clearly labeled provenance.
- Build a static gallery, interactive 3D viewers, offline ZIPs and checksums from
  checked-in records without new model inference.
- Add release checks for host metadata, installed commands, CPU workflow, static
  assets and browser behavior, alongside the scientific unit suite.

This is a research prerelease. It does not establish experimental binding of new
designs or a stable LLM selection advantage. See [known limits](docs/LIMITATIONS.md).
