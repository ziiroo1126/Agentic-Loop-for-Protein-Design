# Adaptive development replay

Open index.html directly in a browser; no server or network is required.
replay.json contains the initial paid observation and event deltas.
ledger.json preserves the accepted actions and host-authored reviews.
Prediction counts are logical acquisition cost, not measured GPU savings.
Only already-paid predictions are exported. Outcomes appear only if the
source session had already revealed its report after all pools committed.
A completed replay is retrospective and must not be used as a blinded
decision interface. Host interpretations are not calibrated probabilities.
source-manifest.json identifies the original private input and code;
private inputs and model weights are intentionally absent from this bundle.
manifest.json checks exported file bytes, not scientific validity.
