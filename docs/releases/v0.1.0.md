# ALPD 0.1.0 — Research Preview

ALPD connects supplied protein binder requirements to candidate generation,
monomer checks, agent-guided complex evaluation and traceable result export.

ALPD is a computational-only research and software project. Wet-lab work is outside
the project scope and is not a release or research-completion condition. Validation
uses computational workflows and offline evaluation; published datasets may supply
existing experimental labels for retrospective comparisons.

Start with the [interactive gallery](https://ziiroo1126.github.io/Agentic-Loop-for-Protein-Design/)
or [quick start](https://github.com/ziiroo1126/Agentic-Loop-for-Protein-Design/blob/v0.1.0/docs/QUICKSTART.md).

Release downloads include the offline demo, a complete recorded case, the ALPD
host skill/plugin bundle, Python wheel/source distribution and `SHA256SUMS`.
Extract the demo and open `demo/index.html`; it needs no model environment.
The host bundle needs a separately installed core and configured host session.

The complete pipeline currently supports a fixed-length linear protein binder
against one fixed protein target. It selects candidates for evaluation; cached
adaptive replay is a separate path. Results are computational diagnostics, with no
claim of measured binding or function for new designs. These cases have not shown
a stable advantage over baseline selection. See the
[known limits](https://github.com/ziiroo1126/Agentic-Loop-for-Protein-Design/blob/v0.1.0/docs/LIMITATIONS.md)
and [verification record](https://github.com/ziiroo1126/Agentic-Loop-for-Protein-Design/blob/v0.1.0/docs/RELEASE_VERIFICATION.md).

Model weights and chemical datasets are not included. Third-party attributions and
original scientific records are retained. This release is intended for research
use and workflow evaluation.
