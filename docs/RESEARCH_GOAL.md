# MolClaw 研究 Goal：何时值得追加一次复合物预测？

日期：2026-09-06。状态：研究目标已确定，以下是待实施方案，尚未完成协议冻结或验证。

## 研究问题

**在候选池、复合物预测模型和评估次数相同的条件下，根据已有预测的不确定性，
自适应选择哪些 binder 候选需要追加预测，能否提高未参与开发的靶点上，最终前
10 名候选的实验阳性比例？LLM 是否在这一决策中提供额外收益？**

主问题检验追加评估的分配机制；LLM 的贡献是单独的次要问题。资源约束在这里用于
公平比较，也对应用户实际能投入多少计算，不是项目的全部动机。

## 为什么从这个问题出发

已有工程流程能够生成候选、运行结构预测、读取反馈，并通过宿主 skill/插件执行。
但在公开数据上的静态四分数筛选中，两轮新增 Codex 决策分别命中 26/60、25/60，
启发式和 ESMFold2 ipSAE 基线均为 26/60；没有稳定的 LLM 排序优势。
见[已归档的重复实验](evidence/BENCHMARK_REPETITIONS.md)。

因此，下一步让系统决定获得什么新证据，并检验这种决策是否有效。
待检验机制是：识别接近入选边界、现有预测不稳定的候选，估计追加一次预测的价值，
把评估机会分配给可能改善最终筛选的对象。不能预先称其为已证实的新颖方法；
还需与主动信息获取、序贯筛选及蛋白设计相关工作比较。

## 最小可检验实验

第一版仅研究固定候选池的复评，不同时改变生成器、候选序列或设计约束。
先采用同一 ESMFold2 模型的多个预测种子，避免把模型更换和调度收益混在一起。
现有公开原始表中有逐种子预测；原先四项聚合分数已经包含后续信息，不能直接作为
这个实验的初始观察。

| 项目 | 拟定规则 |
| --- | --- |
| 每个任务 | 一个靶点的固定候选池，大小为 N，最终选择 10 个候选 |
| 可用预测 | 每个候选同一模型的 5 个种子，顺序预先固定 |
| 初始观察 | 所有候选的第 1 个种子结果；该 N 次预测计入成本 |
| 允许动作 | 为一个候选请求下一个未见种子的预测，或提交最终名单 |
| 主实验预算 | 每个策略最多 3N 次预测，包含初始 N 次；完整预测需要 5N 次 |
| 信息边界 | 仅返回已支付次数对应的评分；未来种子、完整聚合分数及实验标签不可见 |
| 主终点 | 预先指定的实验结合判定；每靶点 Precision@10，再对靶点等权平均 |
| 成本单位 | 回放中为逻辑预测次数；真实运行另测 GPU 时间、峰值显存、总耗时和宿主开销 |

3N 是拟定的中等评估深度，5 个百分点是拟定的实际收益门槛；两者都不是已观察到的
提升。若开发阶段证明这些设定不可执行，必须在读取新测试结果前修改并留档。
不同种子不作为独立生物学样本，预测次数也不直接换算成 GPU 节省或端到端加速。

拟研究的策略使用预测分歧、当前排名与入选边界的距离，以及仅在开发数据上拟合的
可靠性估计，判断下一次评估的价值。具体特征、校准方法、动作规则和超参数须在
独立测试前冻结；不能通过测试结果反复挑选实现。

## 对照与归因

所有可部署策略获得相同初始信息、候选池、动作权限和预算。主要对照共享同一个
最终排序器，单独比较评估分配方式，避免把更换排序器的收益归因于自适应决策。

1. **固定均匀复评**：每个候选再评估两个种子。
2. **固定重点复评**：按初始评分冻结追加评估名单，后续不根据结果改名单。
3. **简单自适应启发式**：按预先固定的分歧与排名边界规则分配评估。
4. **MolClaw 可靠性感知策略**：利用开发数据估计追加评估价值，动态选择下一次动作。
5. **宿主 LLM 策略**：读取与第 4 项相同的观察和可靠性信息，通过受约束工具选择动作。

第 1–3 项中，在开发集表现最好的策略作为唯一主要比较对象，选择规则在测试前冻结。
第 4 项是主方法，第 5 项与第 4 项比较回答 LLM 的额外贡献，不能把两者在测试集上
表现较好的那个事后改为主方法。简单单分数筛选与 5N 完整评估作为补充参考；
完整评估不参与等预算优势判定，也不假设它必然给出最佳名单。

消融至少包括：移除可靠性估计，以及冻结评估分配。随机策略或宿主策略的重复先在
靶点内汇总，再进行靶点级比较；重复次数、提示词与可记录的模型版本在测试前冻结。

## 数据与验证边界

- 已分析的七靶点 630 个候选及其标签全部作为开发资料。既有六靶点结果不能重新
  宣称为未知测试结果，其他已经查阅结果的数据也必须记录暴露情况。
- 独立验证先完成数据可用性、许可、预测覆盖及来源审计，再锁定测试清单。
  目标至少覆盖 6 个未参与开发的靶点；实际样本量须结合开发阶段的靶点级变异评估，
  6 个靶点本身不保证统计把握度。候选重复、序列家族及靶点同源关系须检查并报告。
- 测试数据必须具备预先定义的实验终点和可顺序揭示的逐次预测。只有最终聚合评分的
  数据不足以验证这个问题；若需补算，先测量本地模型成本再确定可执行规模。
- 纳入、排除、未知实验状态和缺失预测的处理规则提前冻结；不得按阳性率筛选靶点。
  闭集回顾性 Precision@10 使用该终点已明确判定的候选池，报告由此产生的覆盖范围
  与选择偏差；未表达、未测及不确定状态不改写为阴性。
- 主实验只使用一个预定终点。来源综合判定须明确注明；跨实验机构的判定分开分析，
  不在看过结果后更换主终点。不能把结构置信度当作实验结合标签。
- 冻结输入、实现、预算、基线选择、主比较和统计方案，再统一揭示测试结果。
  测试标签与未来评分不进入宿主请求，执行层记录所有观察、动作和计费事件。
  公共数据与共享文件系统的泄漏边界仍需如实说明。

## 什么结果支持或不支持假设

主效应是相同 3N 预算下，第 4 项相对开发集选出的主要基线的靶点等权
Precision@10 差值。报告逐靶点结果，以及以靶点为单位的配对 95% 不确定性区间；
区间的具体计算方法、随机种子和重复处理在测试前冻结。

- **达到预定收益标准**：主效应至少为 +5 个百分点，且差值区间下界大于 0。
- **未达到标准**：如实报告。若区间仍很宽，结论是证据不足；若上界低于
  +5 个百分点，则数据不支持预设幅度的提升，不能把“不确定”写成“证明无效”。
- **LLM 贡献**：仅在第 5 项与第 4 项的预定比较中判断；持平或更差时，产品仍可
  使用宿主交互，但不宣称 LLM 提高了科学筛选效果。

其他预算下的曲线、评分校准、不同终点、失败靶点和真实运行成本均为次要分析，
不能替换未通过的主比较。回顾性阳性筛选收益不等于新生成 binder 的湿实验成功。

## Goal 的完成条件

1. 完成相关工作与数据可行性审计，写明这个问题与已有方法的差别及可验证边界。
2. 冻结可执行协议，实现分阶段观察、逐次计费、上述基线、主方法与宿主对照；
   用有针对性的检查验证未来信息隔离、预算约束和可重放性。
3. 完成开发实验及新的独立验证，输出逐靶点结果、预定主比较、消融和失败分析。
   若独立数据不足，保留为未完成验证，不能用重复开发集结果代替。
4. 将同一执行器接入现有 Codex / Claude Code / DeepSeek Harness 共享 skill/插件，
   提供一次真实工具决策案例和可复现回放；分别标注实际验证过的宿主。
5. 交付版本化代码、协议、运行证据和技术报告，并据实更新求职及 PhD 项目叙述。

**完成 Goal 要求完成检验和交付，不要求得到正结果。** 不支持主假设、简单启发式
已经足够、或 LLM 没有额外贡献，都可以成为研究结论；数据不足则不能冒充检验完成。
本阶段不以新基础模型训练、湿实验合成或上线独立网页为前置条件。
